SplitSmart — Dart Expense Splitter

Project Overview

SplitSmart is a beginner-friendly Dart program that helps a group manage shared expenses and calculate how much each member has paid, owes, or should receive.

Features

- Add group members with unique names.
- Record expenses with a title, amount, payer, category and participants.
- Split expenses equally among selected participants.
- List all expenses.
- Filter expenses by member or category.
- Calculate total paid, share owed and net balance.
- Validate invalid amounts, duplicate members, unknown members and empty participant lists.

Technologies Used

- Dart programming language
- Dart SDK
- VS Code

How to Run

1. Install the Dart SDK.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Open the terminal in the project folder.

5. Run:
   
   "dart run main.dart"

Example

If Asha pays ₹900 for Asha, Ravi and Neha, each person's share is ₹300. Asha should receive ₹600, while Ravi and Neha each owe ₹300.

Project Type

Local Dart terminal application. No Flutter UI is required.
